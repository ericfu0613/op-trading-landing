About this project

A personal, non-commercial research dashboard for analyzing Taiwan stock index options (TXO) and futures (TXF). Built by an individual hobbyist trader to study intraday patterns and backtest custom signals.

The system integrates with broker APIs to fetch real-time option chain and underlying futures data, computes Greeks, max pain, GEX, and proprietary cluster classification signals — all visualized in a Plotly/Dash web interface running on localhost.

This is not a commercial product. It is not sold, licensed, or offered to third parties. All trading decisions are made by the project owner for personal account management only.

What the dashboard does

5 functional layers built over 12+ months of research

📊

Real-time option chain

Live TXO chain across active expiries via Shioaji broker API, with Black-Scholes Greeks computed in-process.

🎯

Max Pain & Walls

Live Max Pain calculation, Put Wall / Call Wall detection based on daily open-interest snapshots.

📈

GEX & Gamma Squeeze

Live gamma exposure computation with regime classification (STRONG_LONG / mild_long / mild_short / STRONG_SHORT).

🤖

Cluster Classifier

K-means classification of intraday patterns into 8 clusters (trend / reversal / mixed), with RF predictor for early prediction from morning features.

📉

IV Skew Monitor

Real-time put-call IV skew tracking with alerts on extreme dislocation (P4.6 reversal signal).

💼

Portfolio Greeks

Live delta/gamma/vega/theta tracking for manually entered positions across multiple broker accounts.

TradingView Charting Library integration

We plan to embed the TradingView Charting Library into our self-hosted dashboard for advanced candlestick + technical analysis visualization. The library will receive bar data from our custom UDF datafeed server (Python FastAPI, port 8053) which proxies live Shioaji broker data.

Custom signals (cluster classifier P(strong), Live GEX, Max Pain deviation) will be rendered as virtual symbols and overlay studies via Pine Script. Paper-trade entry markers will be exposed through the /udf/marks endpoint.
